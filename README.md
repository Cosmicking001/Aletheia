# Aletheia · Nebula Discovery Software (early test version)

Type a sky position, or drop in your own image, and Aletheia:

- checks whether the object is already known (SIMBAD, VizieR catalogues);
- flags look-alikes (H II regions, supernova remnants, galaxies, reflection nebulae);
- shows the same field in many surveys (DSS, Pan-STARRS, DECaPS, IPHAS, VPHAS+, WISE, GALEX and more);
- looks for central-star candidates in Gaia DR3 and the white dwarf catalogues;
- writes a cautious evidence scorecard and a PDF report. Everything is a candidate assessment, never a confirmation.

Your images are kept in a private folder on the server and deleted after a day.

Built by Utkarsh Mishra (Shooting Stars Astrophotography). Survey images and catalogues: CDS Strasbourg
(SIMBAD, VizieR, hips2fits, Aladin Lite), Gaia DR3 (ESA), and the survey teams credited in each report.
